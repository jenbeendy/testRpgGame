# Crafting Progression Guide

Visual roadmap of recipe progression from Level 1 to Level 6.

## Beginner Path (Level 1-2)

```
START
  │
  ├─ Smelt Copper (1x ore, 1x coal) → Copper Ingot
  │
  ├─ Cut Planks (1x log) → Oak Plank
  │
  ├─ Craft Wooden Sword (2x plank) → Wooden Sword ⚔️
  │
  └─ Craft Copper Dagger (1x ingot, 1x plank) → Copper Dagger

ARMOR BRANCH (Level 2)
  ├─ Tan Leather (3x scrap, 1x charcoal) → Fine Leather
  │   ├─ Craft Leather Helmet (2x leather, 2x string) → 🎖️
  │   ├─ Craft Leather Chest (4x leather, 1x rope) → 🛡️
  │   ├─ Craft Leather Boots (2x leather) → 👢
  │   └─ Craft Leather Leggings (3x leather) → 👖

CONSUMABLES (Level 2)
  ├─ Brew Health Potion (1x water essence, 1x earth essence) → 🧪
  └─ Craft Repair Kit (1x steel ingot, 1x silk cloth) → 🔧
```

---

## Intermediate Path (Level 2-4)

```
SMELTING BRANCH
  ├─ Smelt Iron (1x iron ore, 2x charcoal) → Iron Ingot
  │   └─ Craft Steel (3x iron ingot, 1x coal) → Steel Ingot
  │       └─ Forge Steel Sword (2x steel, 1x leather) → 🗡️ (Superior)
  │
  └─ Refine Coal (2x coal) → Charcoal ⭐ (Discoverable)

WEAPON BRANCH
  ├─ Forge Iron Sword (2x iron ingot, 1x plank) → Iron Sword (Lvl 3)
  ├─ Craft Iron Bow (1x iron ingot, 1x wooden bow) → Iron Bow (Lvl 3)
  └─ Craft Wooden Bow (2x plank, 1x rope) → Wooden Bow (Lvl 1)

ARMOR UPGRADES (Level 3)
  ├─ Forge Iron Helmet (3x iron, 1x leather helmet) → 🎖️
  ├─ Forge Iron Chest Plate (5x iron, 1x leather chest) → 🛡️
  ├─ Forge Iron Boots (2x iron, 1x leather boots) → 👢
  └─ Forge Iron Leggings (3x iron, 1x leather leggings) → 👖

POTIONS (Level 4)
  ├─ Brew Greater Health Potion (2x basic potion, 1x fire essence) → 🧪⭐
  └─ Brew Mana Potion (1x water essence, 1x air essence, 1x pure crystal) → ✨⭐
```

---

## Advanced Path (Level 4-5)

```
RARE MATERIALS
  ├─ Smelt Gold (2x gold ore, 3x charcoal) → Gold Ingot ⭐ (Discoverable)
  │
  └─ Weave Silk Cloth (2x cloth, 1x air essence) → Silk Cloth ⭐ (Discoverable)

CRYSTAL CRAFTING
  └─ Purify Crystal (3x crystal shard, 1x pure crystal) → Pure Crystal ⭐ (Discoverable)

MAGICAL ITEMS
  └─ Craft Enchanted Staff (1x oak plank, 2x pure crystal, 1x fire essence) → ✨ ⭐ (Discoverable)
```

---

## Expert Path (Level 5-6)

```
LEGENDARY SMELTING
  └─ Smelt Mithril (1x mithril ore, 5x charcoal, 1x pure crystal) → Mithril Ingot ⭐⭐ (HARD)

LEGENDARY WEAPONS
  └─ Forge Mithril Sword (2x mithril, 1x fine leather, 1x pure crystal) → 🗡️⭐⭐ (EPIC)
```

## Recommended Leveling Path

### Session 1 (30 mins, Level 1→2)
```
1. Smelt Copper x5 (95%) = 75 XP
2. Cut Planks x5 (90%) = 75 XP
3. Craft Wooden Sword x2 (95%) = 30 XP
   → Reach Level 2 (180/183 XP)
```

### Session 2 (45 mins, Level 2→3)
```
1. Tan Leather x3 (80%) = 60 XP
2. Craft Leather Helmet x2 (85%) = 40 XP
3. Smelt Iron x5 (90%) = 75 XP
4. Forge Iron Sword x2 (75%) = 50 XP
   → Reach Level 3 (after ~283 XP total)
```

### Session 3 (60 mins, Level 3→4)
```
1. Craft Steel x5 (80%) = 100 XP
2. Forge Iron Armor pieces (70%) = 75 XP
3. Brew Health Potions x10 (80%) = 80 XP
4. Start Forge Iron Sword grinding (75%) = 50 XP each
   → Reach Level 4 (after ~283 XP progression)
```

### Session 4+ (Level 5-6)
```
Unlock discoverable recipes:
- Smelt Gold (requires hints)
- Weave Silk Cloth
- Purify Crystal
- Smelt Mithril (HARD)
- Forge Mithril Sword (EPIC)
```

## Hint System Guide

When undiscovered, hints reveal recipe intent:

```
"Combine coal fragments in heat" → Refine Coal
"Smelt rare golden ore at high temperature" → Smelt Gold
"Legendary mithril requires special handling" → Smelt Mithril
"Combine strong legendary blade components" → Forge Mithril Sword
"Enhance basic potion with fire" → Brew Greater Health Potion
"Blend water and air with crystal focus" → Brew Mana Potion
"Transform cloth into finer material" → Weave Silk Cloth
"Refine multiple crystals into perfection" → Purify Crystal
"Infuse staff with elemental power" → Craft Enchanted Staff
```

Hints become visible when player is **within 2 levels** of recipe requirement.

Example: Level 4 player sees Level 5-6 recipe hints, but not Level 7+

## Success Rate Calculation

Base rate + Skill bonus:
```
Example: Forge Mithril Sword
├─ Base: 60%
├─ Player Level 6, Required 6
│   └─ Bonus: 0% (at requirement)
│   └─ Result: 60%
├─ Player Level 7
│   └─ Bonus: 1%
│   └─ Result: 61%
└─ Player Level 10+
    └─ Bonus: 4% (capped at 100%)
    └─ Result: 64%
```

## Crafting Time Reference

```
1 second:  Quick (coal processing, small items)
1.5-2s:    Standard (basic crafting)
2.5-3s:    Medium (intermediate items)
3.5-4s:    Complex (weapons, armor)
4-5s:      Epic (legendary items)
```

Longer times = higher XP rewards and better crafting narrative.
