## Key Mechanics

### Skill Requirements & Modifiers
- Base success rate is recipe-specific (50-95%)
- +1% success per crafting level **above** requirement
- Capped at 0-100%
- Example: Recipe req Level 3, 80% base
  - Level 1: 80% (too low to boost)
  - Level 3: 80%
  - Level 5: 82% (2 levels above)
  - Level 10: 87% (capped)

### XP Gain Per Craft
- Formula: `10 + (recipe_skill_level × 5)`
- Halved on failure
- Examples:
  - Level 1 recipe: 15 XP (success), 7 XP (failure)
  - Level 5 recipe: 35 XP (success), 17 XP (failure)
  - Level 6 recipe: 40 XP (success), 20 XP (failure)

### Level Progression
- Exponential XP curve: `100 × (level^1.5)`
- Examples:
  - Level 1→2: 100 XP
  - Level 2→3: 283 XP
  - Level 5→6: 1,549 XP
  - Level 10→11: 10,488 XP

### Recipe Chains
- **1-Step** (majority): Single transformation
  - Ore → Ingot
  - Plank + Rope → Bow

- **2-Step** (common): Upgrade path
  - Basic Helmet → Iron Helmet (upgrades leather)
  - Wooden Bow → Iron Bow (reinforces)

- **3-Step** (rare/epic):
  - Mithril Sword: Ore → Ingot → Final + Crystal + Leather

### Discovery System
- 9 recipes marked as discoverable (marked with ~)
- Show hints when within 2 skill levels
- Unlock on first successful craft
- Hints guide players without spoiling

## Durability & Repair

All weapons/armor have **base durability: 100**

### Repair Options
1. **Material Repair**: Consume materials at 50% cost
   - Example: 5 ingots for sword → 2-3 ingots restore 50%

2. **Repair Kit**: Universal consumable
   - Full durability restoration
   - Costs Steel Ingot + Silk Cloth to craft

### Decay
- Time-based: -1 durability/hour (in-game)
- Usage-based: Additional loss when actively used
- Hourly background job checks decay

## Admin Testing

To test crafting as admin:

```bash
# Get auth token
curl -X POST http://localhost:8001/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"password"}'

# Create test recipe
curl -X POST http://localhost:8004/admin/recipes \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Test","result_item_id":1,"success_rate":80,"required_skill_level":1,"crafting_time_ms":1000}'

# Craft item
curl -X POST http://localhost:8002/craft \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"recipe_id":1,"ingredients":{"1":1}}'
```
